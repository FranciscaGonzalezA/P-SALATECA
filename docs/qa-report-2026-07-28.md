## Defectos corregidos durante QA

1. Los filtros API aceptaban fechas inexistentes como `2026-02-30` y horas como `24:00`.
2. JavaScript normalizaba silenciosamente timestamps imposibles con offset, por ejemplo una fecha
   30 de febrero.
3. Una preferencia tipográfica corrupta podía producir la variable CSS `NaN`.
4. El texto del filtro ofrecía búsqueda por dirección, pero el SQL no incluía `m.director`.
5. JSON malformado terminaba como error interno 500 en vez de respuesta cliente 400.
6. Promesas abortadas podían retirar prematuramente el estado de carga de una petición posterior.
7. El detalle no comunicaba explícitamente la ausencia de próximas funciones.

Cada corrección quedó cubierta por pruebas cuando corresponde.
