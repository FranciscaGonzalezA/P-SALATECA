## Condiciones para producción

No publicar como plataforma lista para producción hasta comprobar TLS, privilegios, secretos, respaldo/restauración, alertas, carga real, migraciones y el despliegue. La API actual solo ofrece metadatos y salud; el scraper no tiene conectores productivos. Esta revisión no implementa esas funcionalidades de producto.
